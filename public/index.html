OAuth Clients

For the Claude custom connector (web / desktop / mobile). Create a client, then fill in the Client ID (+ Secret) in the Claude form. It can also be left empty — Claude registers automatically via Dynamic Client Registration.

STEPS IN CLAUDE
  1. Claude → Customize → Connectors → Add custom connector
  2. Remote MCP server URL: fill in …/mcp
  3. Advanced settings: fill in OAuth Client ID and OAuth Client Secret from the "Claude Web" client below (Secret is required for confidential clients)
  4. Click Add, then Connect — the browser opens the console login page for access approval.
